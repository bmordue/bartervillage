# Art asset credits

The source code in this repository is licensed under the MIT licence (see
`LICENSE`). Art assets are licensed separately and are **not** covered by the
source-code licence.

Every asset pack added to the project must be recorded here with:

- the pack name and author,
- the source URL,
- the licence name and a link to the licence text,
- the date the licence was verified, and
- confirmation that the licence permits redistribution in this project.

Do not add an asset pack until its licence has been verified as compatible with
how this project is published (spec §11 and §15).
